# Prototype Basic Data as LOD (PTBD)

This repository contains results for the project "Basisdaten als Linked Open Data" that is carried out as a prototype for the [Swiss data ecosystem](https://www.bk.admin.ch/bk/en/home/digitale-transformation-ikt-lenkung/datenoekosystem_schweiz.html) and is funded by the [Federal Chancellery](https://www.bk.admin.ch/bk/en/home.html).
